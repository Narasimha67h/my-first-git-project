# My Git and GitHub Cheat Sheet









\# 🛠️ Git \& GitHub Cheat Sheet



\### 1. Setup Commands

\* `git config --global user.name "Your Name"` -> Sets your name

\* `git config --global user.email "email@example.com"` -> Sets your email

\* `gh auth login` -> Securely logs into GitHub using your browser



\### 2. Daily Workflow (The 3-Step Loop)

\* `git add .` -> Stages all your file changes (gathers changes)

\* `git commit -m "your message"` -> Takes a local snapshot of your history

\* `git push` -> Uploads your local snapshots online to GitHub



\### 3. Checking \& Undoing

\* `git status` -> Shows what has changed or what needs saving

\* `git log` -> Displays your historic timeline of snapshots

\* `git restore filename` -> The "Undo" button (resets file to last snapshot)
